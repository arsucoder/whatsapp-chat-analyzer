# WhatsApp Chat Analyzer 📊

A **WhatsApp Chat Analyzer** built using **Python, Pandas, Matplotlib, Seaborn, and Streamlit**.

This project analyzes exported WhatsApp chats and provides useful insights such as:

* 📈 Total messages, words, media, and links
* 👤 User-wise message analysis
* 📝 Most common words
* 😀 Most used emojis
* 📅 Monthly and daily activity
* 📊 Interactive charts and visualizations

## 📥 Getting the WhatsApp Chat

To analyze a WhatsApp conversation, first export the chat from WhatsApp.

**Android / iPhone**

Open the WhatsApp conversation you want to analyze and use:

Chat → Export Chat

**Choose:**

Without Media – recommended for this project

The exported chat should contain a .txt file.

**For example:**

WhatsApp Chat with John.txt

## 📊 How to Use

* Start the Streamlit application.
* Upload or provide your exported WhatsApp .txt chat file according to the application's interface.
* Select Overall to analyze the entire conversation.
* Alternatively, select a specific participant.
* Explore the available statistics and visualizations.

The application processes the exported chat and generates analytical insights automatically.
